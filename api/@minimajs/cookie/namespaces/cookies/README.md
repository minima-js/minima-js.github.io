# cookies

Cookie management utilities

## Functions

| Function | Description |
| ------ | ------ |
| [get](functions/get.md) | Retrieves a single cookie value by name. |
| [remove](functions/remove.md) | Removes a cookie by setting its expiration to the past. The cookie is immediately removed from the incoming cookies for the current request. |
| [set](functions/set.md) | Sets a cookie to be sent in the response. The cookie value is immediately available for reading within the same request. |

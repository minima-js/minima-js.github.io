Minima.js API / @minimajs/multipart / getFiles

Variable: getFiles() ​

ts
const getFiles: () => AsyncGenerator<File, any, any> = multipart.files;

Defined in: src/index.ts:27

Retrieves multiple files from multipart form data.

Retrieves all files from a multipart form request as an async iterable. Field data is ignored - only files are processed.

Returns ​

AsyncGenerator<File, any, any>

An async iterable that yields File instances

Example ​

ts
for await (const file of multipart.files()) {
  console.log(file.filename);
  await file.move('/uploads');
}

Example ​

ts
const images = getFiles('images');

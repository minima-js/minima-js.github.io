# searchParams

Utility functions for working with URL search parameters (query string)

## Functions

| Function | Description |
| ------ | ------ |
| [get](functions/get.md) | Retrieves a single search param by name with optional transformation. Throws ValidationError if the param is not found. |
| [getAll](functions/getAll.md) | Retrieves all values for a search param by name with optional transformation. Returns an empty array if the param is not found. |

Minima.js API / @minimajs/server / @minimajs/server / interceptor / error

Variable: error() ​

ts
const error: (cb) => PluginSync<InterceptorRegisterOptions> = createErrorDecorator;

Defined in: work/minimajs/minimajs/packages/server/src/interceptor.ts:121

Creates an error decorator plugin that transforms error responses. Error decorators are executed when an error occurs during request processing. They can modify the error response body before sending it to the client.

Parameters ​

cb ​

ErrorDecorator

Returns ​

PluginSync<InterceptorRegisterOptions>

A plugin that can be registered with app.register()

Example ​

ts
import { interceptor } from '@minimajs/server';
app.register(
  interceptor.error((error, body) => ({
    error: true,
    message: (error as Error).message,
    details: body
  }))
);

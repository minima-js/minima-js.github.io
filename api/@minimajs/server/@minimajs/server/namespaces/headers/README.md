# headers

Utility functions for working with HTTP headers

## Functions

| Function | Description |
| ------ | ------ |
| [append](functions/append.md) | Appends a response header (useful for headers that can have multiple values like Set-Cookie). |
| [get](functions/get.md) | Retrieves a single header value by name with optional transformation. Throws ValidationError if the header is not found. |
| [getAll](functions/getAll.md) | Retrieves all values for a header name with optional transformation. Returns an empty array if the header is not found. |
| [set](functions/set.md) | Sets a single response header. |
